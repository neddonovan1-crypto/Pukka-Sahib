# Ambience recordings (optional)

Drop freely-licensed sitar/tanpura recordings here and the build ships them on
the hosted deploys (adventuresahib.com / Pages) as looped ambience beds,
crossfaded per season. The single-file `index.html` build ignores them (page
weight) and keeps the synthesised ambience, which is also the automatic
fallback while a recording loads or if it fails.

## File names

- `ambience-cold.mp3` / `ambience-hot.mp3` / `ambience-monsoon.mp3` — one bed
  per season, **or**
- `ambience.mp3` — a single bed used for every season.

`.ogg` and `.m4a` also work. Aim for a 1–3 minute seamless loop, mono or
stereo, ~96 kbps; keep each file under ~2 MB. A tanpura drone (with or without
sparse sitar) loops far better than a full performance with a beginning and an
end.

## Licensing — only genuinely free material

Use **CC0 / public-domain** recordings by strong preference (no strings), or
**CC-BY** with the attribution recorded here. Do not use "free for personal
use", YouTube rips, or anything marked NC/ND. Good hunting grounds:

- Wikimedia Commons (filter: CC0 or public domain) — search *tanpura*, *sitar drone*
- Freesound.org (filter: Creative Commons 0) — search *tanpura loop*, *tambura drone*
- Internet Archive — pre-1929 published Indian recordings are US public domain

## Attribution

Record every file in `CREDITS.md` beside it: source URL, author, licence.
CC-BY attribution also gets a line in the site footer.
